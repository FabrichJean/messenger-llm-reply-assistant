Relais Connect — extension de navigateur (Chrome, Edge, Brave, Kiwi…)

Installation (une seule fois) :
 1. Décompresse ce dossier.
 2. Ouvre chrome://extensions (ou edge://extensions), active « Mode développeur ».
 3. Clique « Charger l'extension non empaquetée » et choisis le dossier décompressé.
 4. Recharge la page de ton hub : le bouton « Connecter mon compte Messenger » utilise maintenant ton navigateur.

Ce que fait l'extension : quand tu cliques sur « Connecter mon compte Messenger » dans ton hub, elle ouvre Messenger dans TON navigateur
(ou reprend ta session si tu y es déjà connecté), puis envoie la session à TON hub. Elle ne lit que les cookies de Messenger, rien d'autre,
ne garde rien, et n'agit que si ton hub le demande avec un code à usage unique. Ton mot de passe ne passe jamais par le hub.
